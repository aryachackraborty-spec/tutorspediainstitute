# Tutorspedia Institute

One Roof Solution for Nursery to Class 12 & Skill Development

## Overview

Tutorspedia is a modern, responsive web platform built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**. It showcases a clean, premium design without gradients or AI‑generated look, featuring:

- Dark/Light mode toggle
- Static, user‑ready UI components
- Optimized typography using Google Fonts (Inter)
- Accessible, SEO‑friendly structure

## Features

- Home page with hero carousel and clean stat cards
- Courses sections with updated robotics, primary, and higher secondary images
- Modernized About, Achievements, and Admission sections
- Footer with logo and social links
- Fully responsive layout

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Development

- Edit pages under `app/` or components under `components/`.
- Styles live in `app/globals.css`.
- Dark mode can be toggled from the navigation bar.
